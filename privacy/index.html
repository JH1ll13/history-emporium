Privacy policy

Last updated November 2026.

This site is made for students, including children under 13. We do not ask for, collect or store personal information.

  • No accounts. Students do not sign up or log in.
  • Game progress and any name a student types into a game are saved only in that student's own browser (local storage). That data never leaves the device, and clearing the browser deletes it.
  • Visitor statistics. We may count page visits with Cloudflare Web Analytics, which does not use cookies and does not track individual visitors.
  • Class mode in History Hero. When students choose to join a class game, their devices connect directly to each other using a connection service (PeerJS). Only the game moves and the nickname a student chooses are exchanged.
  • No advertising is shown on this site at this time. If that changes, this policy will be updated first.

Questions? Contact the site owner.
